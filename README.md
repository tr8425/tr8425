## 김태령 (tr8425)

게임 클라이언트 프로그래머입니다. Unity와 C#으로 2D 액션과 모바일 게임을 만들었고, 지금은 웹 프론트엔드와 Claude Code 하네스 설계를 함께 하고 있습니다.

### 출시

- **8Doors: Arum's Afterlife Adventure** (Unity 2D 메트로배니아) 메인 프로그래머 겸 기획. Steam 2021-04, Nintendo Switch 2022-06.
- **BowWow Defense** (모바일 디펜스) 클라이언트. 2024-06 출시.

### 공개 저장소

- [PlayableRecreation](https://github.com/tr8425/PlayableRecreation) RimWorld 1.6 모드. 오락 가구를 식민자 대신 플레이어가 직접 플레이합니다. Harmony 없이 XML 패치 오퍼레이션만으로 코어를 건드리지 않고 확장했습니다. Steam 창작마당 공개.
- [8doors-qa-harness](https://github.com/tr8425/8doors-qa-harness) 플레이 테스트를 자동으로 돌리는 AI QA 하네스의 공개 스냅샷. 에이전트, 스킬, 규칙, 인계 문서만 있고 게임 코드와 에셋은 없습니다.
- [AgentHandover](https://github.com/tr8425/AgentHandover) Claude Code 세션 기록과 git 이력에서 반복 패턴을 찾아 재사용 가능한 에이전트 정의로 바꾸는 TypeScript CLI.
- [TransTaste](https://github.com/tr8425/TransTaste) 외국어 메뉴를 사진으로 찍으면 번역과 알레르기 정보, 맛 프로필을 정리해 주는 모바일 우선 PWA. Next.js 14와 Claude Vision.

### 쓰는 것

Unity (C#) · Godot 4 (C#) · Next.js / TypeScript · Claude Code 하네스 설계

### 작업 방식

개인 프로젝트의 코드는 대부분 Claude Code가 씁니다. 제가 하는 일은 명세를 문서와 스킬로 고정하고, 검증 시나리오를 만들고, 경계에서 판단하는 것입니다. 커밋의 Co-Authored-By 트레일러가 그 기록입니다.
